# luci-app-lb3-ui

针对当前 iStoreOS 三线 `lb3` 原生 nftables 方案的 LuCI 面板。

- 每 2 秒刷新三线在线状态、公网 IP、路由表、实时上下行速率和新连接分布。
- 支持 0-10 权重、单线强制、启停与重启。
- 展示断网看门狗状态和最近一次回退日志。
- 保留 `100.64.0.0/10` 等内网/容器/Tailscale 目的地址绕过规则。
- 后端只暴露白名单操作，不允许网页执行任意命令。
- 使用 `0x6500/0x6600/0x6700` 高位 connmark，避免被 OpenClash 的 `ct mark & 0xff00` 恢复规则清零。
- 随包安装 `/etc/init.d/lb3`，为 101/102/103 三张策略路由表统一建立备用默认路由和 7 条内网/Fake-IP `throw` 路由。

安装前应备份 `/etc/lb3.rules` 和 `/etc/init.d/lb3`。首次“应用调整”会为 nft 规则增加按线路的新连接计数器。

## 定稿修复

低位 mark `0x65/0x66/0x67` 会在 OpenClash 与 conntrack 共存时被掩码操作清零，导致已建立连接的 ACK 或回程包落入主路由表，从其他 WAN 发出。另外，缺少 `throw 192.168.0.0/16` 等路由时，回程内网流量可能命中策略表默认路由后再次发往 WAN。

当前实现使用高位 mark，并在三张路由表中显式绕过私网、CGNAT、链路本地、Fake-IP 和组播网段。这两项修复需要同时存在。

路由器实测：三线策略规则与 7 条 `throw` 路由在服务重启后自动恢复；百度、京东、淘宝、QQ、Bilibili 各 5 次 IPv4 HTTPS 检查全部成功。
